# Document-Image-OCR
# 📄 Document & Image OCR

A Streamlit application that extracts text from PDF documents and images using EasyOCR.

## 🚀 Features

- Upload PDF documents
- Upload JPG/JPEG images
- Extract text using OCR
- Display extracted text in a simple interface

## 🛠️ Technologies Used

- Python
- Streamlit
- EasyOCR
- PyMuPDF (fitz)
- NumPy
- Pillow

## 📂 Project Structure

```
Document-Image-OCR/
│── app.py
│── requirements.txt
│── README.md
```

## ▶️ Installation

```bash
pip install -r requirements.txt
```

## ▶️ Run

```bash
streamlit run app.py
```
